# KinTrace Routines

Use this directory for proposed recurring operator work such as:

- morning project briefs;
- issue/ticket review;
- customer-evidence summaries;
- review reminders;
- project-truth audits.

For each routine define:

- trigger;
- inputs;
- output;
- permissions;
- limits;
- failure behaviour.

Start with read-only or documentation-only routines.

No routine is active by default.

Do not activate schedules, external monitoring, genealogy searches, Git/GitHub writes, deployment, or production-changing automation without explicit authorization.
